# StudySnap Android

A comprehensive modern educational Android application built with Kotlin, Jetpack Compose, and Material Design 3.

## Features
- **Student Dashboard**: Welcome banner, active streak tracker, total points, and daily focus music.
- **Subject-Wise Notes**: Curated educational notes across Biology, Physics, Chemistry, Mathematics, Computer Science, and English with built-in markdown reading mode, AI summaries, and reading point rewards.
- **Daily Knowledge Quizzes**: Interactive quizzes with instant grading, scoring (+20 points), and detailed answer explanations.
- **AI Doubt Solver**: Step-by-step conceptual doubt solver powered by Gemini AI with query synthesis.
- **Student Leaderboard**: Academic rankings with Top 3 Podium (Gold, Silver, Bronze) and VIP badges.
- **Announcements & Academic Calendar**: Official bulletins with priority indicators (High, Medium, Low) and exam schedules.
- **VIP Membership & Profiles**: Custom student profile management and VIP status perks.
- **Admin Management**: Dedicated admin tools to publish notes, announcements, and quiz questions.

## Tech Stack
- **Language**: Kotlin 2.1.0
- **UI Framework**: Jetpack Compose (Material Design 3)
- **Build System**: Gradle 8.8.2 (Kotlin DSL)
- **Architecture**: MVVM with Kotlin Coroutines and StateFlow
- **SDK Targets**: Min SDK 26, Compile/Target SDK 35
